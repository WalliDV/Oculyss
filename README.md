# OCULYSS

**OSINT Intelligence & Digital Exposure Analysis**

*Closed-Source Project | Development Preview*

---

## Overview

**Oculyss** is an independently developed cybersecurity tool focused on Open-Source Intelligence (OSINT), digital footprint discovery, and identity correlation.

The project aims to simplify security investigations by combining multiple OSINT sources into a unified workflow, helping analysts identify publicly exposed information, assess digital exposure, and organize investigation results.

## Key Features

- **Multi-Source OSINT Scanning** — Collects publicly available information across multiple platforms and intelligence sources.
- **Digital Footprint Discovery** — Identifies potential online profiles and exposure associated with usernames and email addresses.
- **Identity Correlation** — Analyzes relationships between discovered results, evaluates confidence, and helps reduce false positives.
- **Exposure Assessment** — Consolidates available breach indicators and publicly exposed identity information.
- **Automated Reporting** — Generates structured HTML investigation reports.
- **Investigation Management** — Supports result validation, evidence consolidation, and structured investigation workflows.

## Technologies

| Technology | Purpose |
|---|---|
| PowerShell | Core application logic, automation and orchestration |
| Python-based OSINT tools | Integration of external investigation utilities |
| REST APIs | External intelligence and data-source integration |
| JSON | Configuration and structured data processing |
| HTML / CSS | Investigation reports and result presentation |

Oculyss is intended for legitimate security research, authorized investigations, and digital exposure analysis.
